# OST — On-Screen Translator

OST는 macOS 26 이상에서 동작하는 메뉴 막대 앱으로, 시스템 오디오를 받아쓰고 기기 내 번역 자막을 플로팅 오버레이에 표시합니다. 영상이나 회의에서 텍스트가 사라지거나 깜빡이거나 중복되는 문제를 심각한 사용성 결함으로 보고 설계했습니다.

## 주요 특징

- Apple Speech와 Apple Translation을 기본 기기 내 공급자로 사용합니다.
- 해당 시스템 로캘을 사용할 수 있으면 Apple Speech에서 영어, 중국어(간체 및 번체), 일본어, 한국어를 지원합니다.
- Qwen3 ASR 및 번역 모델을 선택적으로 설치해 MLX로 로컬에서 실행할 수 있습니다.
- 확정된 받아쓰기 및 번역 기록은 계속 표시하고, 현재 미리보기용으로 별도의 두 줄을 예약합니다.
- 받아쓰기와 번역 영역마다 확정된 내용을 2~10줄로 표시할 수 있으며, 이 값을 변경하면 창 크기도 조절됩니다.
- 기본값은 왼쪽 정렬이며 가운데 및 오른쪽 정렬도 사용할 수 있습니다.
- 원문, 확정 번역문, 현재 번역문 미리보기의 글꼴과 색상을 각각 설정할 수 있고 실시간 예시가 제공됩니다.
- EPD는 번역을 위한 소프트 경계로 사용되며, 멈춤이 발생할 때마다 새 표시 줄을 강제로 만들지 않습니다.
- 앱 UI는 영어, 중국어, 일본어, 한국어를 지원하며 기본 언어는 영어입니다.
- 선택적인 세션별 받아쓰기 및 번역 파일 저장은 기본적으로 꺼져 있으며 사용자가 선택한 폴더에만 저장됩니다.

## 개인정보

오디오, 받아쓰기, 번역은 Mac에서 처리됩니다. OST에는 오디오, 받아쓰기, 번역, 설정 또는 저장된 세션 파일을 컴퓨터 외부로 업로드하거나 전송하는 기능이 없습니다.

인터넷은 사용자가 MLX 모델 다운로드를 선택한 경우에만 사용됩니다. 샌드박스 처리된 다운로더는 모델 파일을 수신하며 사용자 콘텐츠는 전달받지 않습니다.

## 요구 사항

- macOS 26.0 이상
- Apple Silicon

## 0.3.0 설치

[v0.3.0 릴리스](https://github.com/9bow/OST/releases/tag/v0.3.0)에서 `OST-0.3.0-macos-arm64.zip`을 다운로드해 압축을 풀고 `OST.app`을 응용 프로그램 폴더로 옮깁니다.

릴리스 환경에서 Developer ID 인증서를 사용할 수 없어 현재 바이너리는 임시 서명되어 있습니다. 이 저장소에서 다운로드한 파일임을 확인한 뒤에도 macOS 격리 기능에서 앱을 확인할 수 없거나 손상되었다고 표시하면 다음 명령으로 격리 속성을 제거합니다.

```bash
xattr -dr com.apple.quarantine /Applications/OST.app
```

릴리스 ZIP의 SHA-256은 릴리스 워크플로에서 게시하며 다음 명령으로 비교할 수 있습니다.

```bash
shasum -a 256 OST-0.3.0-macos-arm64.zip
```

## 받아쓰기 시작

1. OST를 실행하고 macOS에서 요청하면 시스템 오디오 캡처를 허용합니다.
2. 메뉴 막대에서 OST 자막 아이콘을 선택합니다.
3. 입력 언어와 목표 언어를 선택한 뒤 **시작**을 선택합니다.
4. **설정 > 오버레이**에서 잠금을 해제하고 창을 이동하거나 크기를 조절하거나 확정 줄 수를 변경합니다.

## 마이크 입력

설정 > 일반 > 마이크에서 꺼짐, 받아쓰기만, 받아쓰기 및 번역 중 하나를 선택합니다. 변경 후 캡처를 재시작하세요.

시스템 오디오는 계속 처리하며, 두 입력에 같은 입력 언어와 처리 엔진을 사용합니다. 마이크 입력을 켠 경우에만 macOS에서 마이크 권한을 요청합니다.

설정 > 외형 > 마이크 자막에서 별도 색상을 선택할 수 있습니다. 마이크 받아쓰기, 번역, 미리보기에는 이 색상과 마이크 아이콘이 표시됩니다. 각 입력에는 독립된 두 줄 미리보기가 있습니다. 저장한 마이크 텍스트에는 `[Microphone]` 접두사가 붙습니다.

두 입력을 함께 처리하면 메모리와 처리 시간이 늘어납니다. 스피커 소리가 중복으로 받아써지지 않도록 헤드폰을 사용하세요.

## 주요 용어 우선 인식

설정 > 모델에서 받아쓰기 공급자를 Qwen3 ASR로 선택하고, 주요 용어 우선 인식에 원하는 표기의 짧은 용어를 한 줄에 하나씩 입력합니다. 변경 후 캡처를 다시 시작하면 확정 받아쓰기에서 해당 용어를 참고합니다. 목록을 비우면 용어 힌트가 해제됩니다.

최대 4,000자를 로컬에 저장하며 중복을 제외한 처음 100개 용어를 사용합니다. 실시간 미리보기와 Apple Speech에는 적용되지 않습니다. 인식 결과를 보장하거나 비슷한 단어를 강제로 치환하는 기능은 아닙니다.

## 선택적 세션 파일

**설정 > 개인정보**를 열고 **세션별 기록을 텍스트 파일로 저장**을 활성화한 다음 폴더를 선택합니다. 캡처 시작부터 중지까지의 한 구간이 하나의 세션입니다. OST는 타임스탬프가 포함된 받아쓰기 파일과 번역 파일을 별도로 생성합니다. 이 옵션은 기본적으로 꺼져 있으며 오디오는 저장하지 않습니다.

## 빌드 및 테스트

이 프로젝트는 SwiftPM과 Xcode 앱/XPC 프로젝트를 함께 사용합니다.

```bash
swift package --disable-sandbox resolve
swift test --disable-sandbox --disable-automatic-resolution --jobs 4
script/test.sh
script/build_and_run.sh run
```

릴리스 체크리스트는 [docs/manual-qa.md](docs/manual-qa.md)를 참고하세요.
